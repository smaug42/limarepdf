MPE packages

Package repositories for MPE, a PDF viewer and editor. Both are signed with the MPE release signing key, fingerprint 0CF9 7E88 BAFE E9B6 38D2 14CB EB40 041A 7A8D C801. Updates arrive with your system's own updates.

Debian and Ubuntu

Debian 13, Ubuntu 24.04 and later.

sudo install -d /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/mpe.asc https://smaug42.github.io/mpe/mpe-signing-key.asc
sudo curl -fsSLo /etc/apt/sources.list.d/mpe.sources https://smaug42.github.io/mpe/apt/mpe.sources
sudo apt update
sudo apt install mpe

Fedora

sudo dnf config-manager addrepo --from-repofile=https://smaug42.github.io/mpe/rpm/mpe.repo
sudo dnf install mpe

openSUSE

sudo zypper addrepo https://smaug42.github.io/mpe/rpm/mpe.repo
sudo zypper install mpe

Other systems, and the downloads themselves, are on the Releases page.

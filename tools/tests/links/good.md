# Good links

A file: [other](other.md). A heading: [there](other.md#a-heading-with-code-and-punctuation), and its
repeat: [again](other.md#a-heading-with-code-and-punctuation-1). Here: [top](#good-links). A web link
isn't fetched: [site](https://example.invalid/x.md).

Code doesn't count: `[x](gone.md)`.
